부가가치세2026-11-04대상: 개인사업자대표세무사 신영범

개인사업자 2기 부가세 전 점검 — 간이과세 전환·가산세 4%·노란우산 1,800만원

결론: 7월부터 간이과세로 전환된 사업자는 2기 신고 방식이 달라지고, 가공 세금계산서 가산세는 4%로 무거워졌습니다. 연말 전 매입 증빙을 한 번 더 점검하십시오.

1. 간이과세 배제지역 정비 (2026.7.1.)

  • 전국 544개 배제지역을 정비, 배제지역 내라도 직전연도 공급대가 1억400만원 미만이면 간이과세 적용
  • 유형전환통지서를 받은 경우 별도 신청 없이 자동 적용
  • 2026년 1기(1~6월)는 일반과세자로 이미 신고 — 2기부터 간이과세 방식 적용 여부 확인 필요

2. 거짓세금계산서 가산세 3% → 4%

공급가액 1억원 가공 세금계산서 수취 시 가산세만 400만원이며, 매입세액 불공제와 소득세·법인세 추징이 별도로 뒤따릅니다.

3. 노란우산공제 납입한도 연 1,800만원

납입한도가 연 1,200만원에서 1,800만원으로 확대되었습니다. 소득공제 한도는 사업소득금액 구간별로 별도 적용되므로 본인 구간을 확인 후 납입액을 정하십시오.

신고 전 체크리스트

  1. 홈택스 과세유형 전환 여부 조회
  2. 7~12월 매입 세금계산서 실거래 여부 대조
  3. 중고차 매매업자: 의제매입세액공제 특례 한도(신설) 반영
  4. 노란우산 연내 추가 납입 여부 결정
